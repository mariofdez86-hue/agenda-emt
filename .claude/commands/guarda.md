description: Commit y push a la rama de trabajo
argument-hint: <mensaje del commit>
---
Guarda el trabajo:

1. `git status` y `git diff` para ver qué entra. Enséñame el resumen.
2. `npm run comprueba`. Si falla, para y dímelo: no se guarda roto.
3. Commit con el mensaje `$ARGUMENTS` (en español, imperativo, corto; si no te paso
   mensaje, proponme uno al estilo de los que ya hay en el repo).
4. `git push -u origin claude/shifter-project-setup-1qfduh`.

Nunca a `main`. Nada de pull request si no te lo pido.
